Types of Directives
This are all the built-in directives provided by Angular!

    Structural Directives: => Change appearance of DOM by adding or removing elements.
  • *ngIf: => *ngIf Directive is used to add or remove items based on the if condition.
  • *ngFor: => The *ngFor directive is used to iterate a list of items and then display them. Like the forLoop
  • *ngSwitch: => *ngSwitch is a structural directive used in combination with *ngSwitchCase and *ngSwitchDefault that are both structural directives.
    Attribute Directives: => Change the appearance or behavior of an element.
  • [ngClass]
  • [ngStyle]: => is an attribute directive that updates styles for the HTML element.
  • Component: => Directives with its own template. Refers to the components that consists of four files, html, css, ts and the unit testing one that we hardly touch.
